# AyuDark Privacy Policy

Last updated: August 17, 2026

AyuDark is a Chrome extension that provides a dark mode for Medium.

## Data Collection

AyuDark does not collect, sell, or transfer personal information, browsing history, authentication information, financial information, or personal communications.

AyuDark does not use analytics, advertising trackers, or third-party data collection services.

## Medium Website Content

AyuDark accesses Medium pages solely to apply its dark-mode styling. Page content is processed locally in the user's browser for this purpose and is not transmitted to the developer or third parties.

## Stored Preferences

AyuDark uses Chrome's Storage API to save user preferences, such as the selected dark-mode setting, so that preferences persist between browser sessions.

These preferences are stored using Chrome's extension storage and are not sold or shared with third parties.

## Third Parties

AyuDark does not transfer user data to third parties.

The extension may contain links to external websites such as GitHub or Instagram. These links are optional and are opened only when the user chooses to visit them.

## Changes to This Policy

This privacy policy may be updated if AyuDark's data practices change. Any updated version will be published on this page.
